# みんなのときまきタウン（clockseed）

〜とまった時計塔の小さな街〜

算数・数学のドリルで「時短」をためて、畑と町を育てるブラウザゲームです。
単一ファイル `index.html` だけで動きます（外部ライブラリ・画像ファイル・サーバー・通信なし）。
セーブはブラウザの localStorage に保存されます。

## 遊び方

1. `index.html` をブラウザで開く（GitHub Pages などに置けば、そのURLで遊べます）。タブレットのタッチ操作に対応しています。
2. 開くとタイトル画面が出ます。タップ（またはキーの Enter）で始まります（セーブがあれば続きから、なければチュートリアルから）。タイトル画面でも音のオン・オフを切り替えられます。
   はじめて開くとチュートリアルが始まります。画面下の案内と、光る枠・矢印の目印に沿って進めてください
   （小麦を植える → 時計塔でドリル → 時短で育てる → 収穫・納品 → ガチャ → 町Lv2 → 製粉所 → 小麦粉）。
   いつでも「スキップ」で終われます（確認で「スキップする」を選ぶと終了。それまでの報酬はそのまま残ります）。
3. その後は自由に：
   - **畑**：作物をえらんでタップ（なぞると続けて植える・収穫できる）。区画は町Lvで増えます。
   - **注文掲示板**：作物や加工品を納品すると、ゴールドと町経験値。町Lvが上がると作物・施設・レシピが解放されます（最大Lv8）。
   - **施設**：製粉所・キッチン・パン屋・牧場・乳製品工房・ジャム工房・レストラン・ケーキ屋で加工します。
     施設パネルから **進化**（Lv1→Lv3）できます。費用は建設費×2（Lv2）／×4（Lv3）、工事時間は建設時間と同じ。
     進化すると加工時間が Lv2 で×0.85、Lv3 で×0.70 になります（隣接の−10%とも重なる）。工事中は加工できず、加工の途中は進化を始められません。
     加工中・工事中の施設には、町の画面にアイコン・進み具合のバー・残り時間がいつも出ます。
   - **時計塔のドリル**：難度A（算数）〜E（数学III・C）。問題文と選択肢の数式は MathML で表示します（分数は縦、根号の上線、ベクトルの矢印、定積分の上下端、対数の底）。正解で時短ストックとカケラ。5問＝通常3問＋復習1問＋挑戦1問。
     ためた時短は、育成・建設・加工のタイマーを早めるのに使います（残り25%を切った「追い込み」は2倍消費）。
   - **特殊ドリル**：FACTOR×FACTOR ソロ・イージー（移植版、町Lv3で解放）とテンパズル（移植版、町Lv4で解放）。1日5問までは高効率のごほうび。
   - **ガチャ**：カケラ20個で1回。変種の種・町の飾り・お手伝い・消耗品が手に入り、図鑑に記録されます。
     チュートリアルチケットはカケラの代わりに使えます（1枚＝1回）。
     時計塔の下のカプセルマシンからカプセルが出て開きます（タップで早送り。10連は1個ずつ開けて最後に一覧）。
   - **交換掲示板**（町Lv8で解放）：町のコード `TOKI-TOWN-…` で友だちの町を見学（見学中は何も変わりません）、
     変種のギフトコード `TOKI-SEED-…` で植え付けストックを贈り合えます（文字列を手で渡すだけで、通信はしません）。

## 画面と音

- 画面は3つの帯：上の帯（町Lv・ゴールド・倉庫・ドリル・図鑑・交換掲示板・音のボタン）／中央（町）／下の帯（作物のボタン・案内）。町は中央の帯の中だけに描きます。
- 町を歩くキャラ（水やり少年・鐘で集まる町の人）は、道（石畳・土の通路・広場）の上だけを歩きます。BGM はオルゴール風の8小節ループ（ハ長調・♩=92）です。ドリルの問題文と「こたえは…」は、句読点（、。）の直後と、かっこ書き「（」の直前だけで、行が長くなるときだけ改行します（文節や数式の途中、かっこの中、「）」の直後では割りません。1つのまとまりが長いときは文字を小さくして収めます。例外はありません）。FACTOR×FACTOR の式も、通常ドリルと同じ MathML で描きます。
- スマホは縦画面で遊びます（横向きにすると「縦画面で遊んでね」の案内が出て、縦に戻すまで操作できません。タブレット・PC は横向きでも遊べます）。スマホの縦画面では、ドリルのメニューは説明文なしで、A〜E の大きなボタン（タップするとそのまま5問セット）と特殊ドリルの小さなボタンだけです。
- スマホ向けの表示：上の帯は折り返して全部のボタンが見え、倉庫と作物のボタンは横スクロール、案内文は折り返して全文が見え、パネルは画面に収まって中だけスクロールします。スマホ縦では町が画面の幅に収まる大きさから始まります。指でタップしたときに、新しく出たパネルのボタンが勝手に押されないようにもしてあります。
- 効果音と BGM（オルゴール風）は WebAudio でその場で作ります（音のファイルはありません）。BGM はタイトル画面の「タップではじめる」のタップで鳴り始めます。
- 上の帯の「♪ BGM」「♬ 効果音」で、それぞれ別にオン・オフできます（セーブに保存）。
- 上の帯の出来事の欄に、最新の出来事（作物・加工・建設・進化の完成、納品できる注文、町のレベルアップ）が1行で流れます。タップで直近30件の履歴。
  畑の区画は位置で呼びます（本畑は「A1」〜「D4」、川沿いは西から「川1」〜「川8」）。起動したときは、留守のあいだに終わった分をまとめて知らせます。
- 節目の演出（段階9）：町のレベルが上がると、鐘の音・紙吹雪と花びら・町の人が広場に集まり、続けて「町がLv○になった！」のパネルに、そのレベルで解放されたもの（作物・施設・レシピ・畑の数・特殊ドリル・交換掲示板・町の広がり・家）を一覧で出します（タップで閉じる）。町Lv8 は花火つきの一番大きな形です。
  チュートリアルを終えると、鐘と完了のパネルで祝って、次の目標を1行で示します。
- 時短を使うと、時計塔の歯車が回り、針が早回しで進みます（スキップのパネルの小さな時計も回ります。チュートリアルの時短の場面では、パネルが閉じて時計塔の動きが見えます）。
- 収穫の演出：収穫した作物が弾けて倉庫の方へ飛び、「+3」のような数が出ます。1回のなぞりで続けて収穫するほど収穫の音が高くなり、連続で取れた数（「5個！」）ときらめきが出ます。1回のなぞりで5区画以上取れると、小さな花丸の輪。収穫の判定・量・速さは変わりません（演出だけ）。
- 町の右下の「＋」「−」で拡大・縮小（ピンチ・ホイールも使えます）。いちばん引くと町全体が見えます。

### 検品用のデバッグ

`index.html?debug=1` で開いたときだけ、検品用の `window.__clockseed`（座標や正解の位置を読む API）と
`&fast=10`（育成・建設・加工の時間を10倍速）が有効になります。通常のアクセスでは無効です。
通しテストはすべて `?debug=1` で開きます。`?debug=1&intro=0` のときだけ、タイトル画面と節目のパネル（町のレベルアップ・チュートリアル完了）を出しません（段階8までの通しテストは、この形で従来の流れを確かめます。紙吹雪・鐘・町の人の演出は出ます）。

### 経済シミュレーション

```
node tools/economy_sim.js 300            # 1日15分ドリルのプレイヤーで、町Lv8までの日数・ガチャ回数・時短ストックの傾向を出す
```

ゲームの数値は `?debug=1` の `window.__clockseed.constants()` から読みます（数値の調整はしません。モデルはファイルの先頭に記載）。

## ファイル

- `index.html` … ゲーム本体（ドリル・数式表示（math-render）・ガチャ・FACTOR×FACTOR・テンパズル・交換コードのエンジンは、それぞれ独立した `<script id="…">` に分けてあります）
- `tests/` … 自動テストと通しテスト
- `tools/economy_sim.js` … 経済シミュレーション
- `screenshots/` … 各段階の画面
